# Student Course Portal (Angular 21)

Single incremental Angular enterprise application for Cognizant Digital Nurture Program Week 6.

## Features Implemented
- Student & Course Management Directory
- Data Binding, Custom Directives (`appHighlight`), Custom Pipes (`searchFilter`)
- Template-Driven Student Registration Form with Validation
- Reactive Course Creation Form with `FormArray` & Custom Validators
- Services & Dependency Injection with `BehaviorSubject` State Management
- Angular Router Navigation, Route Parameters (`:id`), AuthGuard & 404 Handler
- HttpClient with `loggingInterceptor`
- Unit Testing with 100% passing test specs

## Commands
- `npm start`: Starts development server on port 4200
- `npm run build`: Builds production bundle
- `npm test`: Runs unit tests
