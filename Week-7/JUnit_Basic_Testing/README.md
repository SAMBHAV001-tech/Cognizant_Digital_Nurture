# Week 7: JUnit Basic Testing

This project contains the mandatory exercises for Week 7 JUnit Testing:

- **Exercise 1: Setting Up JUnit** (`Exercise1_JUnit_Setup`)
- **Exercise 3: Assertions in JUnit** (`Exercise3_JUnit_Assertions`)
- **Exercise 4: AAA Pattern, Setup (@Before) and Teardown (@After)** (`Exercise4_AAA_Setup_Teardown`)

*(Note: Exercise 2 was intentionally excluded as specified by assignment instructions)*

## Build & Test Instructions
Inside any exercise directory, run:
```bash
mvn test
```
All exercises use JUnit 4.13.2 dependency configured in `pom.xml`.
