# Exercise 3: Assertions in JUnit

This exercise demonstrates the core JUnit assertions used to validate test outcomes.

## Assertions Demonstrated

1. `assertEquals(expected, actual)`: Asserts that two values are equal.
2. `assertTrue(condition)`: Asserts that a boolean condition is true.
3. `assertFalse(condition)`: Asserts that a boolean condition is false.
4. `assertNull(object)`: Asserts that an object reference is null.
5. `assertNotNull(object)`: Asserts that an object reference is not null.

## Running Tests
Run the tests using Maven CLI:
```bash
mvn test
```
