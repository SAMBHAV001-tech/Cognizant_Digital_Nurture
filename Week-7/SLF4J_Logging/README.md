# Week 7: SLF4J Logging

This project contains Exercise 1 for Week 7 SLF4J Logging:

- **Exercise 1: Logging Error Messages and Warning Levels** (`Exercise1_Logging_Error_Warning`)

*(Note: Exercises 2 and 3 were intentionally excluded as specified by assignment instructions)*

## Build & Execution Instructions
Inside `Exercise1_Logging_Error_Warning`, run:
```bash
mvn compile exec:java
```
Uses SLF4J API (`slf4j-api`) with Logback (`logback-classic`) implementation to output `ERROR` and `WARN` severity messages to standard console output.
