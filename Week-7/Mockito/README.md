# Week 7: Mockito Unit Testing

This project contains the mandatory exercises for Mockito Testing:

- **Exercise 1: Mocking and Stubbing** (`Exercise1_Mocking_And_Stubbing`)
- **Exercise 2: Verifying Interactions** (`Exercise2_Verifying_Interactions`)

*(Note: Exercises 3, 4, 5, 6, 7 were intentionally excluded as specified by assignment instructions)*

## Build & Test Instructions
Inside any exercise directory, run:
```bash
mvn test
```
All exercises use JUnit 5 (`junit-jupiter`) and Mockito (`mockito-core`, `mockito-junit-jupiter`).
